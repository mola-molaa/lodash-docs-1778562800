Collection 方法用于操作对象、数组、Map、Set 等集合类型的数据结构，提供遍历、转换、过滤、聚合等常见能力，是日常开发中最常用的工具方法集合之一。

## 基础遍历与转换

**示例**
```javascript
import { forEach } from 'your-lib';

// 遍历数组
forEach([1, 2, 3], (value, index) => {
    console.log(index, value);
});
// 输出:
// 0 1
// 1 2
// 2 3

// 遍历对象
forEach({ a: 1, b: 2 }, (value, key) => {
    console.log(key, value);
});
// 输出:
// a 1
// b 2
```

## 过滤与筛选

### filter

遍历集合，筛选出回调函数返回 <Mark bold>truthy</Mark> 的元素，返回新数组。

    <TableRow>
        <TableCell>
            参数名

            类型
        </TableCell>
        <TableCell>

    </TableRow>

    <TableRow>
        <TableCell>
            predicate
        </TableCell>
        <TableCell>
            Function
        </TableCell>
        <TableCell>
            每次迭代执行的筛选函数，返回 truthy 则保留元素，接收 (value, key, collection) 三个参数
        </TableCell>
    </TableRow>
</Table>

**示例**
```javascript
import { filter } from 'your-lib';

// 过滤数组中的偶数
const arr = [1, 2, 3, 4, 5];
const evenNumbers = filter(arr, (value) => value % 2 === 0);
console.log(evenNumbers); // [2, 4]

// 过滤对象中值大于 1 的属性
const obj = { a: 1, b: 2, c: 3 };
const filteredObj = filter(obj, (value) => value > 1);
console.log(filteredObj); // [2, 3]
```

```javascript
const str = reduce(obj, (acc, value) => acc + value, '');
console.log(str); // helloworld
```

## 分组与排序

    <TableRow>
        <TableCell>

        <TableCell>
            类型
        </TableCell>
        <TableCell>

    <TableRow>
        <TableCell>

        </TableCell>
        <TableCell>
            Array / Object / Map / Set
        </TableCell>
        <TableCell>
            待遍历的集合
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            iteratee
        </TableCell>
        <TableCell>
            Function
        </TableCell>
        <TableCell>
            分组依据函数，返回分组 key，接收 (value, key, collection) 三个参数
        </TableCell>
    </TableRow>
</Table>

**示例**
```javascript
import { groupBy } from 'your-lib';

// 按奇偶性分组
const arr = [1, 2, 3, 4, 5];
const grouped = groupBy(arr, (value) => value % 2 === 0 ? 'even' : 'odd');
console.log(grouped);
// {
//   odd: [1, 3, 5],
//   even: [2, 4]
// }

// 按对象属性分组
const users = [
    { name: 'Alice', age: 20 },
    { name: 'Bob', age: 20 },
    { name: 'Charlie', age: 25 }
];
const byAge = groupBy(users, (user) => user.age);
console.log(byAge);
// {
//   20: [{ name: 'Alice', age: 20 }, { name: 'Bob', age: 20 }],
//   25: [{ name: 'Charlie', age: 25 }]
// }
```

        <TableCell>

        <TableCell>
            类型
        </TableCell>
        <TableCell>
            说明
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            collection
        </TableCell>
        <TableCell>
            Array / Object / Map / Set
        </TableCell>
        <TableCell>
            待遍历的集合
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            iteratee
        </TableCell>
        <TableCell>
            Function / String
        </TableCell>
        <TableCell>
            排序依据，函数接收 (value, key, collection) 三个参数，也可直接传入对象属性名字符串
        </TableCell>
    </TableRow>
</Table>

**示例**
```javascript
import { sortBy } from 'your-lib';

// 按数值大小排序
const arr = [3, 1, 4, 1, 5, 9];
const sortedArr = sortBy(arr, (value) => value);
console.log(sortedArr); // [1, 1, 3, 4, 5, 9]

// 按对象属性排序
const users = [
    { name: 'Charlie', age: 25 },
    { name: 'Alice', age: 20 },
    { name: 'Bob', age: 20 }
];
// 先按年龄升序，年龄相同按名字升序
const sortedUsers = sortBy(users, (user) => [user.age, user.name]);
console.log(sortedUsers);
// [
//   { name: 'Alice', age: 20 },
//   { name: 'Bob', age: 20 },
//   { name: 'Charlie', age: 25 }
// ]

// 使用属性名字符串排序
const sortedByName = sortBy(users, 'name');
console.log(sortedByName);
// [
//   { name: 'Alice', age: 20 },
//   { name: 'Bob', age: 20 },
//   { name: 'Charlie', age: 25 }
// ]
```
