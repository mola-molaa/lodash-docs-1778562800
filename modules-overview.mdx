Lodash 是一个高度模块化的 JavaScript 实用工具库，内部将功能拆解为多个独立模块，方便开发者按需引入、降低最终产物体积。

## 模块化引入方式

Lodash 支持多种灵活的引入方式，你可以根据项目需求选择最合适的方案：

### 全量引入

直接引入完整的 Lodash 库，所有方法都可以通过 `_` 对象调用：

```javascript
const _ = require('lodash');
// 或者 ES Module 方式
import _ from 'lodash';

_.chunk([1, 2, 3, 4], 2); // => [[1, 2], [3, 4]]
```

这种方式适合快速开发原型或不需要关注包体积的场景，但会引入全部代码，可能导致最终产物体积偏大。

### 按方法引入

仅引入你需要的单个方法，这是生产环境最推荐的方式，可以最大程度减小包体积：

```javascript
// CommonJS 方式
const chunk = require('lodash/chunk');
// ES Module 方式
import chunk from 'lodash/chunk';

chunk([1, 2, 3, 4], 2); // => [[1, 2], [3, 4]]
```

每个方法都有独立的模块文件，你可以通过 `lodash/方法名` 的路径直接引入。

### FP 模块引入

如果你需要使用 Lodash 的函数式编程风格模块，可以引入 `lodash/fp` 相关方法，该模块的方法默认都是柯里化、参数顺序经过优化的版本：

```javascript
import { map, filter } from 'lodash/fp';

const result = filter(x => x > 2)([1, 2, 3, 4]); // => [3, 4]
```

关于 FP 模块的更多细节，可以参考 <Link href="/fp-module">Lodash FP 模块</Link> 页面。
